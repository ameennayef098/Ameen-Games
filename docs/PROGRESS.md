## ما أُنجز

### 1. ميكانيكية احتفاظ الدور في س.ج
صحيحة ومنفَّذة ومختبَرة — **15/15 اختبار Playwright ناجح**
(`data/reports/test_turnkeep.py`).

| الحالة | النتيجة |
|---|---|
| إجابة صحيحة | نقاط + **يبقى الدور** |
| إجابة خاطئة | خصم + انتقال للفريق الآخر (سرقة) |
| **لم يجب** | السؤال ينتقل للفريق الآخر |
| **لم يجب** مرتين | يُغلق السؤال، ويبقى الدور مع اللي عُرض عليه |
| تجاوز | لا يضيع الدور |

**خطأ حقيقي اكتُشف وأُصلح:** زر «لم يجب» كان يُعطَّل داخل فرع العرض، فالفريق الثاني ما
يقدر يضغطه — حالة «لم يجب الفريقان» كانت مستحيلة الوصول.

### 2. نظام التصميم
- `static/css/style.css` — نظام تصميم كامل (tokens + مكوّنات + responsive)
- `templates/base.html` — navbar, قائمة جوال, footer
- `templates/index.html` — hero, بطاقات الألعاب, الخطوات
- `templates/game_{letters,million,auction,quiz}.html` — صفحات الألعاب
- `templates/{games,about,how_to_play}.html` — الفهرس والصفحات التعريفية
- `templates/admin.html` — يستخدم الـ tokens الجديدة لكنه لم يُعاد تصميمه بالكامل

### 3. بنية التوليد
`tools/gsema.py`, `run_all_waves.py`, `make_plans.py`, `bench_gen.py`, `dedupe_bank.py`,
`استئناف-التوليد.bat`.
