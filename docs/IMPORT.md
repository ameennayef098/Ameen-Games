# استيراد دفعات الأسئلة يدويًا

ميزة إضافة مئة سؤال أو أكثر دفعة واحدة من نص منسوخ، بدون أي ذكاء اصطناعي وبدون
أي اشتراك. التحليل يتم داخل الموقع بمنطق برمجي محض.

## أين تجدها

لوحة الإدارة ← تبويب **«استيراد دفعة»**.

## خطوات الاستخدام

1. اختر **اللعبة** من القائمة — لا تظهر إلا الألعاب الموجودة فعلاً في المشروع.
2. اختر **الفئة** أو **الحرف** — المحددات تتغير حسب اللعبة، فمثلاً «حروف مع أمين»
   تعرض الحروف الـ 28 فقط ولا تعرض فئات «س.ج».
3. الصق النص في المربع الكبير (مئات الأسئلة دفعة واحدة).
4. اضغط **«تحليل النص»**.
5. راجع السجلات في الجدول: الحالة، التحذيرات، زر تعديل لكل سجل، وزر استبعاد.
6. اضغط **«حفظ الأسئلة»** → يظهر ملخص نهائي → تأكيد.

## صيغ النص المدعومة

### 1. النمط الأساسي (س.ج / حروف مع أمين / المليون)

```
س1: ما الكوكب المعروف بالكوكب الأحمر؟
ج1: المريخ

س2: ما الغاز الذي تمتصه النباتات؟
ج2: ثاني أكسيد الكربون
```

المحلل يقبل كلَّ هذه الاختلافات في الترقيم:

| الصيغة | مثال |
|---|---|
| س/ج مع رقم | `س1:` / `ج1:` |
| مسافة قبل الرقم | `س 1:` / `ج 1:` |
| اصلة أو قوس | `س1 -` / `ج1 -` / `س1)` |
| كلمة عربية | `السؤال 1:` / `الإجابة 1:` |
| إنجليزية | `Question 1:` / `Answer 1:` / `Q1:` / `A1:` |
| أرقام عربية مشرقية | `س١:` / `ج١:` |
| سؤال وجواب في سطر واحد | `س1: نص ج1: نص` |
| بلا ترقيم | `س:` / `ج:` (تتابع تلقائي) |

**قواعد ثابتة:**

- الأسطر الفارغة بين السجلات مسموح بها وتُتجاهل.
- السؤال أو الإجابة قد يمتدان على أكثر من سطر.
- النص يُحفظ كما أدخله المستخدم — يُقتصّ فقط من المسافات الزائدة في الطرفين.
- كلمة «سؤال» داخل نص السؤال (مثل «سؤال أول؟») **لا** تُعامل كعلامة ترقيم.
- آخر 500 سجل في الدفعة؛ ما زاد عنها يُقصّ ويُبلَّغ عنه.

### 2. حقول إضافية داخل السجل

```
س1: ما الحيوان الملقب بسفينة الصحراء؟
خيارات: الحصان | الجمل | الفيل | الغزال
ج1: ب
```

| الحقل | الوظيفة |
|---|---|
| `خيارات:` | خيارات «المليون» — تفصل بـ `|` أو `،` |
| `نقاط:` | 200 / 400 / 600 للسجل الواحد (تغلب قيمة اللوحة) |
| `صعوبة:` | سهل / متوسط / صعب / تحت المتوسط |
| `بدائل:` | إجابات مقبولة بديلة |
| `تلميح:` / `شرح:` | حقول «س.ج» الاختيارية |

كتابة الجواب كحرف خيار (`أ` / `ب` / `ج` / `د`) تُحوَّل تلقائياً إلى نص الخيار.

### 3. نمط الحقول (ألعاب المحتوى)

للألعاب التي لا تكون سؤالاً وجواباً تقليدياً, كل سجل يبدأ بـ `سN:` ثم أسطر `الحقل: القيمة`:

```
س1:
الكلمة: صقر
المعنى: طائر جارح سريع البصر
التصنيف: حيوانات
مترابطة: نسر | عقاب | شاهين
```

- القوائم تُفصل بـ `|` أو `؛`، ويمكن كتابتها في أسطر تبدأ بـ `-`.
- عناصر القوائم المركّبة (شخصيات/أدلة/مشتبهون) تكتب `مفتاح: قيمة` وتُفصل بـ `،`:

```
الشخصيات: اسم: أحمد ، دور: مشرف ، قول: غادرت | اسم: سارة ، دور: طالبة ، قول: رأيته
```

كل لعبة لها قالبها الخاص — زر «نسخ القالب» أو «تنزيل القالب» في أعلى الصفحة.

### 4. نمط الأسطر («آخر واحد!»)

كل سطر إجابة تُضاف إلى قائمة التصنيف المختار. الترقيم بـ `سN:` اختياري.

## وضع الحفظ: إضافة أم استبدال

لكل دفعة وضعان، ويختارهما المستخدم من قائمة **«وضع الحفظ»** قبل التحليل:

| الوضع | السلوك |
|---|---|
| **إضافة أسئلة جديدة** | يضيف الدفعة إلى المخزن الحالي. لا يُعدَّل ولا يُحذف أي سؤال سابق. |
| **استبدال** | يحذف الأسئلة القديمة في **نطاق الحذف** ثم يضيف الدفعة مكانها. |

**نطاق الحذف** (يظهر فقط في وضع الاستبدال):

- **اللعبة كاملة** — مثلاً كل أسئلة «حروف مع أمين»، وتبقى «س.ج» و«المليون» كما هي.
- **الحرف / الفئة المحدد فقط** — مثلاً حرف «الفاء» وحده، أو فئة «الرياضة» وحدها.

قبل الضغط على «حفظ الأسئلة» يعرض الموقع عدد الأسئلة التي ستُحذف حالياً،
ويعيد عدّها مرة أخرى في نافذة التأكيد نفسها. لا يمكن التراجع عن الحذف.

**قاعدتان مهمتان:**

- في وضع الاستبدال **لا يُبلَّغ عن التكرار مقابل المخزن**، لأن السجل المكرر هو
  نفسه من سيُستبدل — وإلا لظهرت الدفعة كلها «مكررة» ولم يُحفظ شيء.
- التحقق يبقى قبل الكتابة: إن فشل أي سجل لا يُحذف ولا يُضاف شيء
  (لا دفعة جزئية). موثّق في `tools/test_replace_mode.py`.

## لصق ملف JSON كاملاً

يستقبل مربع النص ملف JSON كما هو، بلا تحويل يدوي إلى صيغة «س/ج»:

- مصفوفة أسئلة: `[{"question": "...", "answer": "...", "letter": "ف"}, ...]`
- أو غلاف يحتويها: `{"questions": [...]}` (يفحص أيضاً `items` / `records` / `data` / `results` / `rows`)

الحقول تُقرأ بأسمائها المخزّنة (`question` / `answer` / `letter` / `difficulty` /
`options` / `category_id` / `category_name` / `points` / `explanation` ...) — أي أن
الحرف أو الفئة أو الخيارات الموجودة داخل الملف أولى من المحددات في اللوحة.

- حدّ الملف: 4 ميغابايت و 5000 سجل (نص «س/ج» يبقى 400 ألف حرف و 500 سجل).
- ملف JSON غير صالح يظهر كخطأ واضح، لا يُتجاهل.
- ملف يحتوي عنصراً غير كائن يعرضه كسجل «غير مكتمل» بدلاً من حذفه بصمت.

### توحيد شكل الحرف

الملفات المجلوبة تكتب الحرف أحياناً بالتطويل («بـ») وأحياناً بدونه، و«هـ» تُكتب
«ه». المحلل يقبل كلا الشكلين ويخزّن شكلاً واحداً:

- الألف بكل أشكالها (`أ` / `إ` / `آ` / `ٱ` / `ا`) تُعدّ `أ`.
- «هـ» (ه + تطويل) تُكتب «ه»، وهو الشكل الذي تعرضه اللعبة.

أول حرف من الإجابة يُحسب بعد تجاهل «ال» التعريف — لذا «الفهد» تبدأ بـ«ف»،
و«أبو بكر» تبدأ بـ«أ»، و«ألكسندر» تبدأ بـ«ك».

| س.ج | س/ج | الفئة، الصعوبة، النقاط |
| من سيربح المليون | س/ج + خيارات | الفئة، الصعوبة |
| آخر واحد! | أسطر | التصنيف |
| مزاد اللاعبين | حقول | الدوري، المركز، الصعوبة |
| كود نيمز | حقول | التصنيف، الصعوبة |

| الرابط المشترك | حقول | التصنيف، الصعوبة |
| أقنعني! | حقول | التصنيف، الصعوبة |

كل لعبة لها محوّل يبني المخطط المخزّن الخاص بها — لا يُفرَض مخطط واحد على الجميع،
ولا تُخترع خيارات أو حقول ناقصة أبداً.

## كشف الأخطاء

كل سجل يأخذ حالة: `صالح` / `غير مكتمل` / `إجابة بلا سؤال` / `يحتاج مراجعة`.

- سؤال بلا إجابة → `غير مكتمل`، ولا يُحفظ.
- إجابة بلا سؤال → `إجابة بلا سؤال`، وتظهر للمراجعة.
- رقم مكرر → يُبقَى السجلان معاً مع تحذير (لا حذف صامت).
- ترقيم غير متسلسل → يعمل عادة، مع ملاحظة معلوماتية.
- أسطر خارج أي سجل (ترويسة أو نص غير مُرقّم) → تُعرض للمراجعة، لا تُخمَّن.
- فئة/حرف غير محدد للعبة التي تتطلبه → `يحتاج مراجعة`.
- فحص المخطط (حروف غريبة، حرف الإجابة لا يطابق الحرف المختار، المليون بلا 4
  خيارات، الحقول الإلزامية الناقصة) يظهر في المعاينة بالسبب الحرفي.

## كشف التكرار

ثلاثة مستويات، كلها تُظهر السبب ولا تحذف شيئاً:

1. **داخل الدفعة** — سؤالان متطابقان في نفس اللصقة.
2. **مقابل المخزن** — السؤال موجود في نفس اللعبة ونفس الفئة/الحرف.
3. **سؤال مقابل إجابة** — نص السؤال مطابق لإجابة مخزنة (احتمال تكرار معكوس).

التطبيع المستعمل: توحيد الألف والهمزات والتاء المربوطة، طيّ المسافات، إزالة
التشكيل — أي أن «ما عاصمة فرنسا» و«ما  عاصمه   فرنسا» يُعدّان واحداً. النص المحفوظ
لا يتغير.

كل سجل مكرر يحصل على مربع **«الاحتفاظ به»** — بدون تحديده لا يُحفظ.

## الحفظ الآمن

القاعدة: **تحقق قبل الكتابة، ثم كتابة ذرّية واحدة.**

- يُبنى كل السجلات ويُتحقق منها **قبل** لمس أي مخزن.
- إن فشل أي سجل، لا يُكتب شيء إطلاقاً (لا دفعة جزئية)، ويُبلَّغ عن السبب لكل سجل.
- الكتابة نفسها عملية `os.replace` واحدة على ملف مؤقت، فلا يمكن لملف JSON أن
  يُكتب نصفه.
- مفتاح **idempotency_key** يمنع تكرار الإضافة عند النقر المزدوج أو إعادة الإرسال:
  الطلب الثاني بنفس المفتاح يُرجع نتيجة الطلب الأول دون كتابة جديدة.
- الاختبار: إعادة الإرسال بنفس المفتاح لا يضيف نسخة ثانية (موثّق في
  `tools/test_import_api.py`).
- لا تُعدَّل ولا تُحذف الأسئلة السابقة ضمن عملية الاستيراد.

## واجهة API

| المسار | الوظيفة |
|---|---|
| `GET /api/import/games` | كل الألعاب مع محدداتها وعدّاداتها وقالبها |
| `POST /api/import/parse` | تحليل النص: السجلات + الحالات + التكرارات + حكم المخطط |
| `POST /api/import/check` | حكم المخطط على سجل واحد بعد تعديله |
| `POST /api/import/summary` | إعادة حساب الملخص بعد التعديل أو الاستبعاد |
| `POST /api/import/save` | الحفظ الآمن (مع `idempotency_key`) |
| `GET /api/import/history` | آخر عمليات الاستيراد |
| `GET/POST /api/import/draft` | حفظ النص الملصوق مؤقتاً إن تعطّل التحليل |
| `GET /api/import/template` | تنزيل قالب اللعبة |
| `POST /api/import/export` | تصدير السجلات المستخرجة JSON / CSV |
| `GET /api/import/count` | عدد الأسئلة التي سيحذفها وضع الاستبدال في نطاق معيّن (للمعاينة) |

### حقول طلب الحفظ

| الحقل | القيم | الافتراضي |
|---|---|---|
| `mode` | `append` / `replace` | `append` |
| `scope` | `game` / `target` | `game` |

`scope` لا يُطبَّق إلا مع `mode=replace`. و`POST /api/questions/import` (الاستيراد
القديم لملف JSON) يقبل أيضاً `replace: true` ليسقط أسئلة الألعاب الموجودة في الملف
قبل إضافة ملفه.

كل مسارات `/api/import*` محمية برمز المشرف مثل بقية مسارات الإدارة.

## حدود متبقية

- **الاستيراد نص أو JSON ملصوق فقط** — لا رفع ملف من الجهاز في تبويب «استيراد دفعة».
  أما الاستيراد القديم عبر `/api/questions/import` فيستقبل ملف JSON (زر «استيراد»
  في تبويب الأسئلة).
- **الحد الأقصى 500 سجل في دفعة «س/ج»** و 5000 في دفعة JSON (يُبلَّغ عن القصّ).
  يمكن تكرار الدفعة.
- **القوائم المركّبة** (`مفتاح: قيمة`) تعتمد على `،` للفصل بين الأزواج و `|` بين
  العناصر؛ نص يحتوي فاصلة عربية داخل قيمة قد يُقسَّم خطأً — يظهر ذلك كتحذير في
  المعاينة ويمكن تعديله يدوياً.
- **التحقق من الصيغة ليس تحققاً من صحة المعلومة علمياً** — الموقع يتحقق من البنية
  فقط ولا يدّعي صحة الإجابة.
- **سجل الاستيراد يُحفظ في `data/questions/import_history.json`** (50 عملية)،
  وهو ملف تشغيل وليس جزءاً من المحتوى.
