# 🎲 لودو الأسئلة والكروت — نسخة HTML/CSS/JS

لعبة طاولة عربية كاملة (بدون كمبيوتر — كل اللاعبين على نفس الجهاز)، مبنية بملفات ثابتة فقط:
لا تحتاج Node.js ولا قواعد بيانات ولا خادم — ترفعها على أي موقع وتشتغل مباشرة.

## 📁 الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة (ترويسة الموقع + شاشة الإعداد + شاشة اللعب) |
| `style.css` | كل التصميم — الألوان في متغيرات بأعلى الملف |
| `game.js` | منطق اللعبة كاملًا (المحرك + العرض) مع تعليقات عربية |
| `questions-data.js` | بنك الأسئلة (80 سؤالًا: ثقافة عامة + رياضيات) |

## ▶️ التشغيل محليًا

افتح `index.html` بنقرة مزدوجة في المتصفح — هذا كل شيء.
(أو شغّل خادمًا محليًا: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`)

## 🌐 الرفع على موقع ألعاب أمين

1. ارفع الملفات الأربعة داخل مجلد في موقعك (مثلًا `/games/ludo-questions/`).
2. أضف رابط اللعبة في قائمة ألعاب موقعك: `https://موقعك.com/games/ludo-questions/`
3. أو للتضمين داخل صفحة موجودة استخدم iframe:

```html
<iframe src="/games/ludo-questions/index.html"
        style="width:100%;max-width:900px;aspect-ratio:4/3;border:0;border-radius:12px"
        allow="fullscreen"></iframe>
```

## ✏️ أين أعدّل؟

### 1) ألوان الموقع (لتطابق تصميم موقعك تمامًا)
في **أعلى `style.css`** تجد:

```css
:root {
  --portal-dark: #1e2a5e;   /* كحلي الترويسة والتذييل */
  --portal-blue: #2563eb;   /* الأزرق الأساسي */
  --portal-bg:   #eef2f9;   /* خلفية الصفحة */
  --green:       #22c55e;   /* أزرار اللعب */
  ...
}
```

غيّر هذه القيم فقط وسيتغير الموقع كله. اسم الموقع والروابط في `index.html`
(ابحث عن `navbar` — الروابط حاليًا `#` وضع بدلها روابط أقسام موقعك).

### 2) إعدادات اللعبة
في **أعلى `game.js`** تجد كائن `CONFIG`:

```js
const CONFIG = {
  CHANCE_A: 0.15, WEIGHT_A: 60,  // 60% من الأدوار ← فرصة كرت 15%
  CHANCE_B: 0.30,                // و40% من الأدوار ← فرصة كرت 30%
  MAX_CARDS: 4,                  // أقصى عدد كروت باليد
  TIMER_SECONDS: 20,             // مدة مؤقت السؤال
  RESULT_PAUSE: 2600,            // مدة عرض نتيجة الإجابة
  DEFAULT_PLAYERS: 2,            // عدد اللاعبين الافتراضي
};
```

### 3) الأسئلة
في `questions-data.js` — أضف أو عدّل أي سؤال بنفس البنية:

```js
{
  id: "GK-99",              // معرف فريد
  category: "general",      // general أو math
  difficulty: 1,            // 1 سهل، 2 متوسط، 3 صعب
  question: "نص السؤال؟",
  options: ["أ", "ب", "ج", "د"],
  answer: 0                 // فهرس الإجابة الصحيحة (يبدأ من 0)
}
```

لا يشترط عدد معين من الأسئلة — اللعبة تعيد تدوير البنك عند استنفاده.

### 4) قواعد الرقعة (لمن يريد تعمقًا)
داخل `game.js` تجد ثوابت واضحة: `STARTS` (خلايا البداية)، `SAFE_CELLS` (الخلايا الآمنة)،
`HOME_COLUMN` (أعمدة البيت)، و`CONFIG` أعلاه — كل قسم مشروح بتعليق عربي.

## 🧩 القواعد داخل اللعبة

- كل رمية نرد يتبعها سؤال من 4 خيارات — الصحيح يتحرك، الخطأ يفقد دوره.
- تحتاج **6** لإخراج حجر من القاعدة، ورمية **6** تمنح رمية إضافية (3 ستات متتالية = ضياع الدور).
- بعد كل إجابة صحيحة وحركة: فرصة كرت (15% أو 30% حسب الدور).
- الكروت تُستخدم ببداية دورك: 🎯 خطوات (1–12)، 🔄 تبديل موقعين، ↩️ إرجاع 4 خطوات.
- 4 كروت كحد أقصى — الكرت الخامس إما تستبدل به كرتًا من يدك أو ترفضه.
- الفوز: إدخال الأحجار الأربعة إلى المركز.
